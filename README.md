# 微缩交通沙盘 · 路网生成器

基于 **SolidJS + MapLibre GL JS** 的三维地形路网编辑沙盘。在起伏地形上放置路口、连接道路、
约束连接角度,所有操作实时贴合地形高度渲染,并支持完整的撤销/重做与文件导入导出。

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

## 四区域布局

| 区域 | 位置 | 职责 |
| --- | --- | --- |
| **地图视口** | 左侧主区域 | MapLibre 自定义 WebGL 图层渲染地形/道路/路口,承载全部鼠标交互 |
| **路口编辑面板** | 右侧栏 | 节点坐标、连接角度约束、吸附容差、相邻路口列表、删除接续 |
| **道路样式面板** | 右侧栏 | 主次两级宽度档位、5 种路面材质,整条道路全分段联动更新 |
| **路网图** | 右侧栏 | 2D 缩略图显示全部节点/连接,点击节点视口飞行定位 |

顶部为工具条(选择/放置/连接/拆分/删除 + 撤销/重做),底部为数据管理(导入/导出/本地存储)。

## 核心能力

### 路网建模
- **放置路口**:切换「放置路口」工具后在沙盘平面点击,射线拾取地形交点作为节点坐标
- **连接道路**:「连接道路」工具依次点击两个路口生成路段,自动拒绝重复连接
- **两级道路**:主干道 14m、次干道 7m,不同宽度带状网格渲染
- **中点拆分**:「中点拆分」工具在每条边显示中点手柄,点击即在该点插入路口并把一段拆为两段,
  两条新边共享同一 `roadId`,样式天然联动
- **删除接续**:删除路口时,同属一条道路的两条邻边自动接续为一条新边

### 地形贴合与渲染
- 程序化地形(正弦起伏 + 高斯山丘 + 盆地),无需外部 DEM 或瓦片
- 道路带状网格按 8m 间隔采样,每个顶点重新采样地形高度并计算法线
- 路口圆盘铺面 + 相邻道路间的**环形扇形圆角连接**,转弯处自然圆滑
- 路面材质通过片元噪声模拟颗粒感(沥青/混凝土/块石/碎石/积雪)

### 角度约束
- 路口可设置约束轴角度(0/45/90/135 预设或滑块自定义)与吸附容差
- 拖动经过不满足约束的位置时,自动投影到最近合法射线(约束轴及其反向)
- 视口中以橙色虚线实时绘制约束轴,面板可一键归位

### 交互
- 左键拖动路口(相连路段实时重算长度走向并重贴地形)、右键平移、Shift+右键旋转俯仰
- 滚轮缩放、双击放大;快捷键 `V/P/C/S/D` 切换工具、`Ctrl+Z/Y` 撤销重做、`Delete` 删除选中
- 全部结构性修改进入 100 步深度的历史栈;拖动在结束时一次性入栈

### 数据
- 导出为 version 1 的 JSON 文件(路口/道路/边三类实体),可重新导入
- 支持浏览器 localStorage 临时保存;导入时校验引用完整性,悬空边自动丢弃

## 架构

```
src/
├── types.ts              # 实体模型(Intersection/Road/Edge)
├── constants.ts          # 沙盘尺寸、路宽、材质表、抬升量
├── store/network.ts      # Solid 信号仓库 + 命令式操作 + 撤销/重做历史
├── lib/
│   ├── terrain.ts        # 程序化高度场、法线、角度吸附数学
│   ├── geometry.ts       # 地形/道路/圆角/节点网格构建
│   ├── projection.ts     # 本地米坐标↔经纬度、MVP 逆矩阵射线拾取
│   ├── mat4.ts           # 极简列主序矩阵库
│   └── bus.ts            # 缩略图定位事件总线
├── map/
│   ├── SandboxLayer.ts   # MapLibre 自定义图层(对象字面量,WebGL1/2 兼容)
│   ├── MapView.tsx       # 地图视口:指针交互、拾取、拖动、工具编排
│   ├── overlay.ts        # 2D Canvas 叠加层(约束轴/拆分手柄/橡皮筋)
│   └── camera.ts         # 地图实例与飞行定位
└── components/           # 工具条、两个编辑面板、路网图、导入导出面板
```

### 关键实现说明

- **自定义图层用对象字面量而非 class**:MapLibre 内部把自定义图层包装为 `StyleCustomLayer`,
  会提升对象自身属性;class 原型方法在该路径下会丢失导致 `render` 不被调用。
- **索引格式自适应**:检测 `OES_element_index_uint` 扩展,不支持时降级 Uint16
  (地形网格顶点数控制在 65535 以内)。
- **网格更新后手动 `triggerRepaint()`**:自定义图层内容在 render 周期外变更,
  MapLibre 不会自动重绘。
- **拾取独立于渲染网格**:维护一张 40×40 的粗粒度三角网做 Möller–Trumbore 射线求交,
  避免把高密度渲染网格用于每帧鼠标检测。
