# 器官网格裁剪编辑工具（术前规划）

基于 **TypeScript + React + three.js + three-mesh-bvh** 的器官网格平面布尔裁剪与断面编辑工具。
导入重建好的器官三维模型后，用可拖拽的平面刀沿任意方向做布尔裁剪，自动提取并高亮断面
边界闭合环，支持沿环吸附补洞、断面平移与顶点级微调、按器官独立的撤销/重做、断面测量与
模型导出。

## 运行

```bash
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5180）
npm run build      # 类型检查 + 生产构建
npm test           # 几何自检 + 状态层端到端测试（Node，无需浏览器）
```

## 界面四模块

| 区域 | 模块 | 功能 |
| --- | --- | --- |
| 左栏 | ① 模型导入区 | 拖拽/选择导入 OBJ、STL、GLTF、GLB；器官列表切换、删除，各器官独立历史 |
| 中央 | ② 裁剪工作区 | 3D 视口、可拖拽平面刀、模式工具条、刀位实时读数、操作提示 |
| 右栏上 | ③ 断面编辑面板 | 边界环选择、周长/面积测量、自动/手动补洞、断面平移、顶点微调入口 |
| 右栏下 | ④ 历史与导出 | 撤销/重做、操作栈浏览、OBJ/STL/GLB/GLTF 导出 |

## 操作流程

1. **导入**：把模型文件拖入导入区。模型自动居中、归一化、焊接为 indexed 网格并建立 BVH。
2. **摆刀**：进入「刀平移」或「自由旋转」模式，用 X/Y/Z 三个轴向预设刀位或自由旋转档定位；
   也可直接在刀面上按住拖动平移，或用偏移滑块、翻转法向微调。
3. **裁剪**：拖动平面刀时断面**实时重算（预览，不入栈）**；点击「提交裁剪入栈」固化为一次
   可撤销/重做的操作。裁空会被阻止。
4. **断面环**：裁剪产生的开口自动提取为闭合环并金色高亮，标注序号。
5. **补洞**：
   - 一键自动补洞：对全部断面环用 earcut 三角化封闭；
   - 手动补洞：进入「手动补洞」模式，沿高亮环依次点击，拾取点**吸附到最近边界环顶点**，
     ≥3 点后提交，生成带内部调整点的封闭断面。
6. **微调**：「顶点微调」模式拖动青色调整点（点击断面空白可追加调整点）；断面编辑面板可
   沿法向整体平移断面。所有微调都进入操作栈。
7. **测量/导出**：面板实时显示所选环的周长、面积、顶点数、法向；导出当前裁剪结果分享。

快捷键：`Ctrl+Z` 撤销，`Ctrl+Y` / `Ctrl+Shift+Z` 重做。

## 需求与实现对照

| 需求 | 实现 |
| --- | --- |
| 平面刀任意方向布尔裁剪 | `geometry/clipPlane.ts`：逐三角形按有符号距离分裂，BVH `shapecast` 粗筛候选三角形 |
| 带断面轮廓的开口模型 | 切割交点焊接并标记 `aCap=1`，断面与器官网格分材质 group |
| 边界自动提取为闭合环并高亮 | `geometry/boundaryLoops.ts`：拓扑边界边 + 切割点过滤 + 邻接行走；`three/loopHighlights.ts` 金色 LineLoop |
| 沿环手动补洞、顶点吸附 | `three/SceneManager.pickBoundaryVertex` 最近环顶点吸附；`geometry/fillHole.ts` earcut 三角化 |
| 拖动平面刀断面实时重算 | 预览几何不入栈，节流到每帧一次，提交才入快照 |
| 三轴预设刀位 + 一档自由旋转 | `KnifePlane.applyPreset`（X/Y/Z/FREE）+ 四元数自由旋转 |
| 裁剪结果与轮廓联动 | store 订阅驱动，几何与高亮/标签/调整点统一重建 |
| 断面平移与顶点级微调 | `editorStore.translateCap`（连通分量整体平移）、`moveCapVertex`（aCap=2 内部点） |
| 操作栈、撤销/重做、重做完全还原 | 每器官独立快照栈，快照持有完整几何与环，重做即整体还原 |
| 多器官切换、独立历史 | `EditorStore` 按 organ id 维护独立 snapshots/cursor |
| 断面周长/面积测量 | `geometry/measure.ts`（Newell 法向 + 多边形面积、边长求和） |
| 导出分享 | `geometry/exportModel.ts`：OBJ / STL / GLB / GLTF，断面保留独立材质 |
| 数千面拖动流畅 | BVH 加速，2 万面单次裁剪约 15–35 ms（见自检输出） |
| 多次裁剪后吸附/撤销一致性 | 几何自检 24 项 + 状态层测试 30 项覆盖斜切、二次裁剪、吸附、撤销重做 |

## 关键工程决策

- **快照式历史**：每次提交保存完整 `BufferGeometry` 与边界环，撤销/重做只移动游标，
  从根本上保证"重做后断面与轮廓完全还原"，避免增量逆操作的累积误差。
- **预览与历史分离**：拖动只更新临时预览几何并即时释放上一份，内存平稳且不污染操作栈。
- **切割点精确焊接**：相切情形下同一几何点会同时以源顶点和退化交点存在，用 1e-7 容差
  （远小于边长）仅在刀平面切割点间焊接，并剔除由此产生的退化三角形，保证边界环度数为 2、
  严格闭合。
- **补洞用复制顶点**：断面环顶点是吸附坐标的复制体而非共享顶点，使整个断面可独立平移，
  吸附约束（坐标重合 1e-6）由测试守护。
- **断面身份保持**：再次裁剪时按原 group 材质标记保留断面三角形身份。
