# 眉睫曲线塑形工作室

一个使用 **TypeScript + SolidJS + Three.js** 实现的三维眉形 / 睫毛曲线编辑工具。所有编辑都发生在程序化三维面部上，支持手绘眉形主线、控制点塑形、镜像联动、逐根睫毛参数、成排复制、橡皮擦、完整撤销重做、眼部特写以及 JSON 导入导出。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址（默认 Vite 地址）。生产构建：

```bash
npm run build
npm run preview
```

## 操作说明

### 眉部模式

1. 左侧工具选择 **手绘主线**。
2. 在一侧眉骨位置按住并描绘主线，松开后自动：
   - 重采样为 5～6 个控制点；
   - 生成宽度变化、末端可收尖的眉体；
   - 按当前浓密档位沿主线生成眉丝。
3. 拖动金色控制点改变弧度。
4. 拖动选中点旁的蓝色八面体手柄，或使用右侧滑杆，上下调整该点眉宽。
5. 右侧可分别调整起端、末端收尖程度，以及稀疏 / 自然 / 浓密档位。
6. 默认镜像开启时，普通控制点编辑会按 `x → -x` 对称跟随。
7. 单侧微调：
   - 按住 `Alt` 拖动控制点 / 粗细手柄；或
   - 勾选左侧 **单侧微调** 后拖动；或
   - 在右侧弧段列表中手动 **断开** 指定段。
   
   独立弧段可随时点击 **恢复联动**，并立即从当前编辑侧重新对称同步。

### 睫毛模式

- 选择 **摆放睫毛**，沿上眼睑边缘点击或拖动即可逐根摆放。
- 直接拖动已有睫毛可改变其眼睑位置。
- 选中睫毛后调节：
  - 长度；
  - 卷翘角度（末端沿卷曲参数曲线上翘）；
  - 粗细。
- 点击 **成排复制 9 根** 可沿眼睑复制成扇形排。
- 选中排后可设置 **整排旋转角** 和排层偏移，也可复制为新的一排。
- 橡皮擦点击删除单根睫毛；点击眉体删除整侧眉。按住橡皮擦拖动可连续删除睫毛。

### 视角 / 历史 / 文件

- 空白区域拖动旋转视角，滚轮缩放，右键 / 双指平移。
- **眼部局部精修** 会将相机平滑推进到当前侧眼睛。
- `Ctrl/Cmd + Z` 撤销，`Ctrl/Cmd + Shift + Z` 或 `Ctrl + Y` 重做。
- `D / V / E` 分别切换绘制、选择调整、橡皮擦。
- **导出文件** 保存完整 JSON；**导入** 可恢复眉部控制点、弧段镜像状态、密度、收尖、每根睫毛参数和排组。

## 性能设计

数百根睫毛如果各自使用独立 Mesh，会产生大量 Draw Call。项目中的 `LashBatch` 将所有睫毛写入同一个动态 `BufferGeometry`：

- 固定管状分段，单根睫毛在几何体中占据固定顶点 / 三角形区间；
- 全量修改（如成排旋转、导入、撤销重做）时重建合批几何体；
- 单根长度 / 卷翘 / 粗细变化时只重写该睫毛的顶点区间；
- 三角形编号可直接映射回睫毛 ID，因此合批后仍可精确拾取和擦除单根。

面板中的 **生成 480 根压力示例** 可直接验证数百根睫毛场景。

## 主要目录

```text
src/
├─ App.tsx                  # Solid 界面、工具状态、导入导出与操作接线
├─ components/NumberSlider.tsx
├─ editor/
│  ├─ types.ts              # 可序列化文档模型
│  ├─ model.ts              # 默认模型、镜像、描边重采样、排复制、JSON 归一化
│  ├─ store.ts              # Solid Store + 快照式撤销重做
│  ├─ faceGeometry.ts       # 面部曲面、眼睑曲线、眼部坐标
│  ├─ browView.ts           # 宽度眉体、收尖包络、眉丝 InstancedMesh
│  ├─ lashBatch.ts          # 睫毛卷曲曲线与合批管状几何体
│  └─ SceneManager.ts       # Three.js 场景、拾取、指针塑形、相机特写
└─ styles.css
```

## 数据格式

导出的 JSON 顶层为 `ProjectDocument`：

```ts
{
  format: 'brow-lash-studio',
  version: 1,
  mirror: true,
  brows: { left: Brow, right: Brow },
  lashes: Lash[],
  rows: LashRow[]
}
```

撤销重做保存完整文档快照，因此回退后控制点坐标、弧段联动标记、浓密档位以及每根睫毛的参数和排组归属都会原样恢复。
