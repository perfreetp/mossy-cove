# 铸造浇冒口布置与浇道网络编辑工具

面向铸造工艺员的三维浇冒口工艺设计台：在三维铸件上布置浇口杯、直浇道、横浇道、内浇口与冒口，
节点连线生成浇道管体，管径调整时全网络流量按截面积比例实时重算，并对比例失衡节点红色预警。

技术栈：**TypeScript + Svelte 5（runes）+ three.js + Vite**

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查通过后的生产构建
npm run check      # svelte-check 严格类型检查
```

浏览器打开以下页面可运行无头/手工测试（共 45 项断言）：

- `http://localhost:5173/test.html` — 纯逻辑：流量守恒、截面积比例分配、失衡、断流、吸附、测距、撤销重做（12 项）
- `http://localhost:5173/test-store.html` — Svelte 仓库端到端：Proxy 深拷贝回归、实时调径重算（20.9%→42.4%）、
  断开归零、断开重连、冒口封顶 8 个、热节测距（21 项）
- `http://localhost:5173/test-export.html` — 导出文件结构与 CSV 内容校验（12 项）

## 功能模块

界面顶部为四个模块标签页，左侧是当前模块面板，右侧是检查器，底部为状态栏。

### 1. 浇道绘制
- **放置节点**：选择节点类型（浇口杯 / 直浇道底窝 / 横浇道节点 / 内浇口 / 自由节点），
  在三维空间或铸件表面点击放置。
- **连线成管**：依次点击两个节点，自动生成浇道管体，并按起止节点推断类型与层级。
- **管径调整**：选中管段后拖动中点白色手柄（增量式，可连续增大/缩小），
  或在右侧检查器拖动滑块；拖动过程中整条网络的流量分配实时重算。
- **长度调整**：直接拖动节点，所有相连管段长度随节点位置实时变化。
- **吸附**：节点靠近其它浇道端点（默认 20 mm 容差）时显示绿色指示环并自动对齐，可在顶栏开关。

### 2. 节点编辑
- 节点列表增删（删除节点会一并移除关联浇道）。
- 浇道连接列表：下拉框**断开重连**任意端点（保持管径不变），或一键**断开**。
- 断开后下游管段流量立即归零，全网络重新分配；断流节点半透明显示并在面板列出。
- 分叉均衡监测：失衡节点（超过阈值）红色预警列表。

### 3. 冒口布置
- 进入放置模式后在**铸件顶面**点击放置冒口，自动约束在顶面 footprint 内。
- 冒口**数量上限 8 个**，达到上限后放置按钮禁用并提示。
- 自动测量冒口颈到**最近热节**的连接距离（扣除热节半径），虚线连接并在标签/面板显示。
- 支持三种铸件（箱体 / 台阶件 / 筒体）与尺寸参数，热节按形状自动生成。
- 冒口直径、高度可拖动滑块或三维手柄调整。

### 4. 导出
- **JSON 方案文件**：完整数据（铸件、节点、通道、冒口、流量校核汇总），可重新导入继续编辑。
- **CSV 工程量表**：通道管径/长度/截面积/流量份额、节点流入比例、冒口热节距离（带 BOM，Excel 直接打开）。
- 导出前校核卡片显示节点数、浇道数、冒口数、失衡与断流统计。

## 核心计算规则

| 项目 | 规则 |
| --- | --- |
| 流量来源 | 浇口杯（cup）为根节点，多杯均分总入流 1.0 |
| 分叉分配 | 按下游通道截面积比例 `qᵢ = Q · Aᵢ / ΣA`，`A = πd²/4` |
| 三级层级 | L1 直浇道（主，默认 Ø28）／ L2 横浇道（次，Ø20）／ L3 内浇口（末，Ø12） |
| 节点标签 | 显示流入比例与各下游分出比例 |
| 失衡判定 | 分叉比例相对理想均分 1/N 的最大偏差，归一化后超过阈值（默认 15%）→ 节点变红 |
| 断流 | 与根节点不连通的节点流入为 0，半透明显示并计入未接入列表 |
| 冒口距离 | 冒口颈位置到最近热节表面（中心距 − 热节半径） |

## 撤销 / 重做

`HistoryStack`（上限 100 步）覆盖：节点增删、移动、浇道连接/断开/重连、管径调整、
冒口增删与尺寸调整、铸件参数修改。快捷键 **Ctrl+Z / Ctrl+Y**（Delete 删除选中，Esc 取消）。

## 目录结构

```
src/
├── lib/
│   ├── types.ts        领域模型与常量（RISER_LIMIT=8）
│   ├── geometry.ts     向量、面积、格式化等纯函数
│   ├── flow.ts         拓扑排序 + 截面积比例流量分配 + 失衡判定
│   ├── history.ts      撤销/重做快照栈
│   ├── snapping.ts     端点吸附
│   ├── meta.ts         节点/通道/层级元数据与通道类型推断
│   ├── casting.ts      铸件三维几何、热节生成、顶面约束、冒口测距
│   ├── sample.ts       初始示例方案
│   ├── exporter.ts     JSON / CSV 导出
│   ├── viewport.ts     three.js 场景、拾取、拖拽、CSS2D 标签
│   └── store.svelte.ts Svelte 5 runes 中央状态仓库（$state/$derived）
├── components/         Svelte 界面组件（顶栏/四模块面板/检查器/状态栏/视口）
├── App.svelte
├── app.css
└── main.ts
```

所有长度单位为毫米（mm）。
