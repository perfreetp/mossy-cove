# CT/MRI 病灶体积测量与剖面查看工具

一个纯前端的三维医学重建模型分析工具。技术栈为 **TypeScript + Vue 3 + Three.js + manifold-3d (WASM)**，项目数据保存在浏览器 IndexedDB，可导出单个 JSON 文件进行分享和重新导入。

## 启动

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
npm run preview
```

建议使用最新版 Chrome / Edge。Manifold 的布尔运算通过 WebAssembly 在浏览器本地执行，模型和标注不会上传到服务器。

## 功能模块

### 1. 模型载入

- 支持常见网格格式：`.stl`、`.obj`、`.ply`、`.glb` 以及自包含 `.gltf`（外部 `.bin` 资源建议先打包为 `.glb`）
- 自动合并多 Mesh、转换为位置网格、焊接重复顶点并居中包围盒
- 显示当前/原始面片数、顶点数和包围盒 X/Y/Z 尺寸
- 四档网格简化：原始、轻度、均衡、流畅
- 简化网格不适合布尔时，CSG 自动回退到原始闭合网格

没有自己的模型时，可点击“示例器官”生成一个闭合的变形椭球进行体验。

### 2. 病灶勾画

- 进入勾画模式后，在器官表面点击放置控制点
- 控制点按顺序连成闭合轮廓
- 使用 `ExtrudeGeometry` 沿轮廓平均法线拉伸为病灶实体
- 厚度可在 2–60 mm 间调节
- 边缘圆滑共 4 档，通过 bevel 分段实现
- 支持对两个已有病灶执行：
  - 合并：A ∪ B
  - 求差：A − B
- 可选择布尔后保留参与病灶；默认移除，避免体积重复统计

### 3. 体积测量

- 每个病灶与器官执行 Manifold 布尔求交
- 显示：
  - 原始拉伸体积
  - 器官内实际占用体积
  - 占器官体积比例
  - 当前剖面截面积
- 体积单位按模型单位为 mm 处理，`1000 mm³ = 1 mL`
- 可设置 mL 体积阈值；严格超过阈值的所有病灶同步切换为琥珀色脉动高亮材质
- 阈值变化会同步更新三维材质和剖面轮廓颜色

### 4. 剖面查看

- X / Y / Z 三个常用切面方向
- 可通过滑杆调整平面位置，也可直接在视窗拖动青色平面或边缘圆球
- Three.js 材质级 clipping plane 同时裁剪器官和病灶
- 使用三角面—平面求交生成切口线段，连接截面环并投影到平面计算截面积
- 支持翻转保留侧
- 可切换：
  - 器官 + 病灶
  - 只看病灶
  - 只看器官

## 数据保存、导出与恢复

- 所有状态修改会防抖写入浏览器 IndexedDB
- “导出标注/报告”下载一个 JSON 项目文件，包含：
  - 原始器官网格（Base64 编码的 `Float32Array` / `Uint32Array`）
  - 网格简化档位
  - 全部病灶控制点、厚度、圆滑档位、颜色和可见性
  - 病灶网格及与器官求交后的占用网格
  - 体积、比例、截面积和布尔历史
  - 体积阈值
  - 剖面法线、位置、启用状态和翻转状态
  - 视图模式和当前选中病灶
- “导入项目”读取该 JSON，恢复全部病灶、测量结果和剖面位置

> 导出的 JSON 内含网格二进制的 Base64 文本，大型模型会使文件较大。

## 目录结构

```text
src/
  components/          Vue 面板、视口和提示组件
  lib/
    geometry.ts        文件读取、网格焊接、简化、轮廓拉伸和几何统计
    manifold-engine.ts Manifold WASM 初始化与布尔/求交封装
    section.ts         平面求交、截面环连接和截面积计算
    serialization.ts   Base64 网格序列化与项目文件校验
    storage.ts         IndexedDB 键值存储
    types.ts           共享类型
  state/
    controller.ts      全局响应式状态、业务动作、导入导出和自动保存
  three/
    Viewer.ts          Three.js 场景、拾取、材质、裁剪平面和拖动交互
```

## 医学使用说明

本项目是三维网格测量与交互可视化工具，不构成医疗器械或诊断结论。体积和截面积的准确性取决于输入 CT/MRI 重建网格的比例、水密性和分割质量。若模型不是闭合流形，显示、简化和剖面仍可工作，但精确布尔求交可能失败；界面会显示对应的 Manifold 状态。
