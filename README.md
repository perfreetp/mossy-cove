# 微缩建筑楼层拆分工作台

基于 **Svelte 5 + Three.js + manifold-3d** 的微缩建筑拆分与剖切工具。场景、楼层列表、剖切控制、操作历史四个工作区同步联动，所有几何切分和截面均由 Manifold WASM 进行实体布尔运算，而不是仅使用 Three.js 裁剪平面。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址（默认 `http://127.0.0.1:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现能力

- **内置体块**：退台塔楼、阶梯台地、L 形街角楼三种多层建筑。
- **按高度拆分楼层**：输入楼层数后，用水平层高盒与整体建筑做 Manifold 求交。每层都是独立封闭实体，求交过程自动生成楼层底面/顶面封盖。
- **楼层列表**：自顶向下逐层显示，颜色与三维楼层一致；支持点选、眼睛图标隐藏/显示、一键抽离/归位。
- **单层编辑**：
  - Three.js `TransformControls` 直接平移、旋转、缩放；
  - 检查器中可精确输入 X/Y/Z 位移、角度和比例；
  - 可隐藏或把该层抽离到沙盘旁边，其他楼层保持原堆叠位置。
- **任意方向剖切**：
  - 水平面、X 纵剖、Z 横剖、任意斜面预设；
  - 可直接编辑法向向量 `(x, y, z)` 和平面方程 `n·P = d` 中的距离 `d`；
  - 场景中有剖切面边框、方向箭头和可拖拽手柄，拖动手柄即沿当前法向移动平面。
- **真实封闭截面**：
  - 每个被剖到的楼层先经坐标变换到该层局部空间；
  - 使用 `Manifold.splitByPlane()` 得到保留侧封闭实体；
  - 再用两次平面修剪得到一层恒定世界厚度的橙色薄实体封口截面；
  - 楼层列表同步显示“剖切中”徽标并高亮。
- **拆分与剖切联动**：修改楼层数会重新生成所有楼层实体，当前剖切面法向和距离保持不变，并立即重新计算各层截面与高亮。
- **撤销 / 重做 / 任意历史步骤**：
  - 放入体块、重新切分、单层变换、隐藏、抽离、剖切方向、剖切拖动等均有序记录；
  - 滑块和 Gizmo 的一次连续手势只产生一条历史；
  - 历史面板可点击任意步骤回退，也可重做。
- **导出 / 导入分享文件**：
  - 导出 `.json` 工程文件，包含当前沙盘状态和完整历史栈；
  - 另一台机器通过“导入”即可恢复楼层变换、隐藏/抽离、剖切位置和历史。

## 操作

- 左键拖动：旋转视角
- 滚轮：缩放
- 右键拖动：平移视角
- 点击楼层：选择
- `W / E / R`：切换平移 / 旋转 / 缩放 Gizmo
- `Ctrl/Cmd + Z`：撤销
- `Ctrl/Cmd + Shift + Z` 或 `Ctrl + Y`：重做

## 几何说明

楼层状态只保存可序列化数据（楼层数、各层变换、可见性、抽离状态、剖切面参数和历史快照）。Manifold 对象和 Three.js GPU 资源不进入历史或导出文件；恢复状态时由确定性的内置体块重新生成。

剖切平面在世界坐标中定义为：

```text
n_world · p_world = d
```

若某个楼层的局部矩阵为 `p_world = A p_local + t`，则传入 Manifold 前转换为：

```text
(Aᵀ n_world) · p_local = d − n_world · t
```

因此即使该楼层已经被单独平移、旋转或缩放，剖切位置仍与整个沙盘的世界坐标平面一致。
