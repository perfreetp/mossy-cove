# 骨鉴 · 骨骼碎片三维拼接复原工具

基于 **TypeScript + Vue 3 + Three.js + manifold-3d** 的浏览器端法医骨骼碎片拼合取证工具。所有模型、特征点和案件数据均保存在本机 IndexedDB，不依赖后端；可导出 JSON 项目包分享，也可导出最终位姿与拼接组结构报告。

## 启动

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
npm run preview
```

建议使用最新版 Chrome / Edge，并启用 WebGL /硬件加速。生产构建会把 Manifold WASM 一并打包到 `dist/assets/`。

## 标准操作流程

1. **碎片导入与归类**
   - 点击“导入碎片”，或直接把 `.obj` / `.stl` / `.ply` 文件拖入窗口，可一次多选。
   - 文件名中的数字会自动识别为编号，例如 `femur_03_left.stl` → `03`。
   - 支持按股骨、胫骨、肱骨、椎骨、骨盆、颅骨等类别归类，可搜索、筛选、改编号、调色和调整透明度。
   - 可载入 12 块演示碎片，或用 300 块碎片做交互流畅度压测。

2. **断口配准**
   - 在列表中点击一块，再 `Ctrl/⌘/Shift + 点击` 第二块；也可在三维视图中 Ctrl 多选。
   - 点击“添加对应点对”，先点 A 碎片断口特征点，再点 B 上的对应点。
   - 至少采集 3 组不共线对应点后，点击“计算粗配准”。
   - 系统使用 **Kabsch + SVD** 求刚体变换，将 B 贴合到 A，并计算每组特征点残差、RMS、平均和最大残差。
   - 残差超过阈值时，会在三维视图中用红色箭头标出从基准点到实际贴合点的偏差方向。

3. **锁定与接触判定**
   - 点击“Manifold 接触判定并锁定拼接组”。
   - 系统将碎片当前世界矩阵送入 `manifold-3d`：
     - `intersect()` 计算实体布尔交集和穿插体积；
     - `minGap()` 计算接触最小间隙；
     - 超阈值穿插会显示红色交集体并阻止锁定。
   - 判定通过后形成拼接组。拖动组内任意碎片都会把 TransformControls 附着到整组，所有成员实时联动。
   - 拼接组可一键拆分，成员恢复为独立刚体。

4. **整体校正**
   - 选择参考骨骼或碎片，系统从顶点协方差提取 PCA 主轴线。
   - 可将全部碎片和拼接组绕共同中心整体旋转，对齐到世界 X / Y / Z 轴。

5. **保存、分享与导出**
   - 项目变更会防抖自动保存到浏览器 IndexedDB，刷新后自动恢复。
   - “导出完整项目包”生成 `.bonepack.json`，内嵌几何 Base64、编号类别、特征点、姿态、组和评估结果，可在另一台浏览器通过“导入项目包”恢复。
   - “导出位姿报告”生成最终 JSON，包含：
     - 每块碎片的世界坐标、四元数、欧拉角、缩放和 4×4 矩阵；
     - 每个拼接组的 ID、名称、成员 ID/编号和组姿态；
     - 配准残差与 Manifold 穿插判定结果。

## 主要目录

```text
src/
├─ App.vue                    # 主界面与工作流面板
├─ controller.ts              # 用例编排：导入、配准、锁定、拆分、导出、存档
├─ store.ts                   # Vue reactive 状态与非响应式几何缓存
├─ types.ts                   # 项目/位姿/拼接组/报告类型
├─ three/BoneViewer.ts        # Three.js 场景、选择、Gizmo、拾取、辅助可视化
└─ lib/
   ├─ importFiles.ts          # OBJ/STL/PLY 导入、网格焊接、几何序列化
   ├─ manifold.ts             # Manifold WASM 初始化、实体转换、布尔/间隙判定
   ├─ storage.ts              # IndexedDB 与项目包序列化
   ├─ demo.ts                 # 演示与压力测试碎片
   └─ utils.ts                # Kabsch/SVD、PCA、Base64、位姿工具
```

## 性能设计

- Three.js 像素比限制在 1.75，避免高分屏几百碎片时过度填充。
- 几何对象和大型二进制缓存不放入 Vue 深度响应式系统。
- 射线拾取只在点击时执行，不为鼠标移动做持续全量检测。
- 列表行使用 `content-visibility: auto`，降低几百行 DOM 的布局开销。
- TransformControls 直接驱动真实 `THREE.Group`，组成员联动由 Three.js 矩阵完成，无需逐块手写变换。
- 300 块低/中模碎片在常规桌面浏览器中可保持实时旋转、缩放和 Gizmo 操作流畅。

## 注意事项

- 配准只求旋转和平移，不做缩放；法医测量场景应保持导入单位一致。
- Manifold 布尔判定要求网格可构造为闭合、定向、二流形实体。导入的扫描模型若有破面、非流形边或重复碎片，工具会明确提示“非流形/无法实体判定”并阻止在未验证状态下锁定；可先在 MeshLab、Blender 或 Geomagic 中补洞、法向一致化和焊接顶点。
- 特征点是粗配准输入；点选精度和分布会直接影响 RMS。建议在断口边缘选择 4 个以上分散、不共线的解剖特征点。
- 清除浏览器站点数据会删除 IndexedDB 自动存档；结案后请导出 `.bonepack.json` 和位姿报告归档。
